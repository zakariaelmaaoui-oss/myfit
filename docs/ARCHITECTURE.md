# SHADOW FIT — Architecture

A personal AI "Hunter System" for fitness, nutrition and discipline. Original artwork; inspired by the *atmosphere* of
RPG "system" stories (ranks, quests, holographic windows) — no copyrighted characters, logos or assets.

## 1. Stack

| Layer | Choice | Why |
|---|---|---|
| UI | React 18 + TypeScript + Tailwind CSS (Vite) | Fast SPA, typed, utility styling with a custom neon design system |
| Hosting | Vercel (static app + serverless functions in `/api`) | Already connected to the GitHub repo |
| Auth + DB | Supabase (Auth, PostgreSQL, Row Level Security, private Storage) | Real persistence, per-user security |
| AI | Groq API, `openai/gpt-oss-120b` (configurable `GROQ_MODEL`) with **structured tool calling** | Free tier, understands Darija/Arabic/French/English, verified tool calling |
| Food data | USDA FoodData Central (SR Legacy) bundled + user custom foods; AI estimates are stored and **labelled "estimate"** | Reliable reference values |
| Photos (optional) | Pexels API (`PEXELS_API_KEY`) for recipe photos; private Supabase bucket for progress photos | Licensed images |
| Push (optional) | Web Push (VAPID) + Vercel Cron for morning/evening messages | Works with the PWA |

Secrets (`GROQ_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `VAPID_PRIVATE_KEY`, `PEXELS_API_KEY`, `CRON_SECRET`) live **only** in Vercel
server environment variables, never in frontend code.

## 4. THE SYSTEM — AI agent

`POST /api/system` (authenticated with the user's Supabase token; all DB access runs **as the user**, so RLS applies).

Loop: build context (profile, targets, today's totals, quests, plan, memory) → call the model with tools → execute
each tool server-side with validation → send tool results back → repeat (max 6 steps) → stream the final answer.
The chat UI shows each executed action as a card **only from real tool results** (success or error).

Tools (JSON-schema, validated server-side):

| Tool | Effect |
|---|---|
| `get_day_summary(date?)` | calories/macros eaten, remaining, water, quests, workout |
| `search_foods(query)` | USDA + custom foods |
| `log_food(meal, items[{name, grams, food_id?, kcal?, protein?, carbs?, fat?}])` | inserts food logs; unmatched items saved as `ai_estimate` |
| `delete_food_log(id)` | removes an entry |
| `suggest_meals(remaining_kcal, protein, meal, count)` | from the recipe library, filtered by allergies/budget |
| `log_exercise(exercise, sets[{reps, weight?, seconds?}], rpe?)` | records sets, updates PRs, quests, XP |
| `complete_workout(session_id?)` | closes the session, awards XP, evaluates progression |
| `get_training_plan()` / `generate_training_plan(goal?, days?)` | read / create a program from the exercise library |
| `adjust_difficulty(exercise, direction, reason)` | manual easier/harder |
| `get_quests(date?)` / `complete_quest(id)` / `generate_quests(date)` | daily checklist |
| `log_weight(kg, waist?)` / `log_water(ml)` | body + hydration |
| `get_progress(period)` | trends for charts and answers |
| `remember(fact)` | durable memory |

Safety rules in the system prompt + server checks: no targets below ~1200 kcal (women) / 1500 kcal (men), no
"burn it off" or skipping meals, no XP for starving or over-training, rest days enforced, medical topics referred to
professionals, never claims an action that has no successful tool result.

## 5. RPG engine (deterministic, unit-tested)

* **XP sources:** workout completed (+50–120 by duration/effort), quest completed (+10–40), meals logged (+5 each,
  max 4/day), protein target reached (+20), water target (+10), weekly challenge (+150), streak milestones.
  Never for calorie deficits or extra training beyond the plan.
* **Level curve:** `xpForLevel(n) = round(100 × n^1.5)`. **Rank** from level: E 1–9, D 10–19, C 20–34, B 35–49, A 50–69, S 70+.
* **Attributes (0–100):** Strength ← strength sets/PRs; Endurance ← cardio minutes; Discipline ← quests completed;
  Consistency ← active days in last 28; Fitness Level ← blend of the four.

## 6. Adaptive difficulty ("Evolving Hunter")

Per exercise, after each session: if all prescribed sets were completed, RPE ≤ 8 and form OK in **2 consecutive
sessions** with ≥ 48 h recovery → progress one step (+2 reps, or +5–10 s, or harder variation at the rep cap). If
sets were missed or RPE ≥ 9 twice → step back. Otherwise hold. Rest days and a deload week every 5th week. XP never
changes difficulty.

## 7. Daily rhythm

Morning: quests generated (rules + AI wording) and motivation. Pre-workout: objectives. Post-workout: celebration,
XP, improvements. Evening: evaluation. Weekly (day 7): AI report stored in `weekly_reports`; targets only change on
multi-day trends, never on one unusual day.
